Carry Look-Ahead Adder

4-BIT · PARALLEL CARRY COMPUTATION · DIGITAL LOGIC

Generate Function
Gᵢ = Aᵢ · Bᵢ
Bit i generates a carry regardless of Cᵢ
Propagate Function
Pᵢ = Aᵢ ⊕ Bᵢ
Bit i propagates an incoming carry forward
Look-Ahead Carry Equations
C₁ = G₀ + P₀·C₀
C₂ = G₁ + P₁·G₀ + P₁P₀·C₀
C₃ = G₂ + P₂·G₁ + P₂P₁·G₀ + P₂P₁P₀·C₀
C₄ = G₃ + P₃·G₂ + P₃P₂·G₁ + P₃P₂P₁·G₀ + P₃..P₀·C₀
Sum Computation
Sᵢ = Pᵢ ⊕ Cᵢ
Since Pᵢ = Aᵢ⊕Bᵢ, this gives
Sᵢ = Aᵢ ⊕ Bᵢ ⊕ Cᵢ ← Full Adder sum
