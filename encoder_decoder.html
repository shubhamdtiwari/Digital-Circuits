ENCODER — KEY POINTS
Basic: Only 2 OR gates for 4:2
Problem: Two inputs active simultaneously gives wrong output
Solution: Priority encoder — higher index wins
Valid flag: Indicates at least one input is active
Size: 2ⁿ inputs → n output bits
DECODER — KEY POINTS
Gates: n AND gates + NOT gates
Enable: EN=0 → all outputs LOW
Expansion: Two 2:4 decoders + EN pin = 3:8 decoder
Minterm: Each output = one minterm of inputs
Size: n input bits → 2ⁿ outputs
DECODER AS LOGIC CIRCUIT
Each output = one minterm!

Any Boolean function can be implemented by OR-ing the required minterm outputs:

F(A,B) = Σm(1,2,3)
→ OR outputs Y₁, Y₂, Y₃

Decoder = Universal logic!
ENCODER APPLICATIONS
Keyboard Encoder — each key press → unique binary code sent to CPU
Priority Interrupt — CPU determines highest priority interrupt
A/D Converters — analog comparator outputs encoded to binary
Octal/BCD Encoder — standard IC building blocks
DECODER APPLICATIONS
Memory Chip Select — address decoder selects which RAM/ROM chip is active
7-Segment Display — BCD decoder drives display segments
CPU Instruction Decode — opcode decoded to control signals
Demultiplexer — decoder + data input = DEMUX!
