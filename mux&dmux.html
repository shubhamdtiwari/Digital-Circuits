4:1 MUX — BOOLEAN EXPRESSION
Y = S₁'S₀'·I₀ + S₁'S₀·I₁ + S₁S₀'·I₂ + S₁S₀·I₃

Each select combination acts as an AND gate — only the selected input passes through to Y.

Gate count: 4 AND gates + 1 OR gate + 2 NOT gates
1:4 DEMUX — BOOLEAN EXPRESSIONS
Y₀ = D·S₁'S₀'
Y₁ = D·S₁'S₀
Y₂ = D·S₁S₀'
Y₃ = D·S₁S₀

Only one output is active at a time. Input D passes to the selected output; all others are 0.

MUX APPLICATIONS
Data Routing — select which data source reaches the bus
Function Generator — implement any Boolean function
Parallel→Serial — convert parallel data to serial stream
Signal Selection — pick one of multiple sensor signals
DEMUX APPLICATIONS
Data Distribution — send one source to multiple destinations
Memory Decoding — select which memory chip is active
Serial→Parallel — convert serial data to parallel
Display Drivers — drive one of many output devices
MUX AS UNIVERSAL LOGIC
A 4:1 MUX can implement any 3-variable Boolean function by connecting input variables to select lines and setting data inputs to 0 or 1.

An 8:1 MUX can implement any 4-variable function — making MUX a universal logic element!
