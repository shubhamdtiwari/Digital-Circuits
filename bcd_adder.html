BCD ADDER

BINARY CODED DECIMAL · CORRECTION LOGIC · DIGITAL ARITHMETIC

✅ Example 1 — No Correction
5 + 4
0101 + 0100
Stage 1: 1001 (= 9)
C₄ = 0, S₃·S₂ = 0
K = 0 → No correction
Result: 1001 = 9 ✓
❌ Example 2 — Correction Needed
6 + 7
0110 + 0111
Stage 1: 1101 (=13, invalid!)
S₃·S₂ = 1 → K = 1
Add 0110: 1101+0110
Result: Cout=1, 0011 → "13" ✓
⚠️ Example 3 — Carry Overflow
9 + 9
1001 + 1001
Stage 1: C₄=1, sum=0010
C₄=1 → K = 1
Add 0110: 10010+0110
Result: Cout=1, 1000 → "18" ✓
Correction Condition (K)
K = C₄ + S₃·S₂ + S₃·S₁
C₄=1 → sum ≥ 16 (overflow)
S₃·S₂=1 → sum is 12–15
S₃·S₁=1 → sum is 10–11
Gate Implementation
AND gate 1: S₃ · S₂
AND gate 2: S₃ · S₁
OR gate: C₄ + (S₃S₂) + (S₃S₁)
K controls: add 0110 or 0000
Final Carry Out
Cout = K
(The correction flag itself becomes
the carry to the next BCD digit)
Multi-digit: chain BCD adders
